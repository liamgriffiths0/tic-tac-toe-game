# Tic Tac Toe

A classic two-player browser game.

## Features

- Two-player gameplay
- Winner detection
- Draw detection

## How to Use

Take turns placing X and O on the board.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Complete a row to verify winner detection.
- [ ] Play a round ending in a draw.
- [ ] Reset the board and verify the next player starts correctly.
